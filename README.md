# Personal Profile and Quiz Web App

## Project details
A responsive personal profile webpage for a B.Tech CSE student. It includes a profile introduction, skills section, contact details, dark/light theme toggle and a five-question multiple-choice quiz.

## Features
- Personal introduction and profile header
- Skills displayed as interactive tags
- Responsive layout for desktop and mobile
- Dark/Light Mode toggle using JavaScript
- Five-question quiz with answer validation and final score
- Hover effects on buttons and skill tags

## Technologies used
- HTML5
- CSS3
- JavaScript

## Run locally
1. Download or clone this project.
2. Open `index.html` in a web browser.
3. Edit the name, email, skills and profile details in `index.html`.
